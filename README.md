# Disaster Management System

The **Disaster Management System** is a web application designed to assist in disaster management efforts. The system integrates weather forecasting, volunteer coordination, and communication features to streamline disaster response.

## Features

- **Weather Forecasting**: Integrated with weather APIs to provide real-time updates on disaster-prone areas.
- **Volunteer Registration**: A platform for volunteers to sign up and be notified of disaster response efforts.
- **Email Notifications**: Automated emailing system to notify volunteers and helpers about critical updates.
- **Mapping Feature**: An interactive map to help track disaster areas and assist in coordination.

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **APIs**: Google APIs (for email notifications), Weather APIs (for real-time updates)
- **Mapping**: Google Maps API
